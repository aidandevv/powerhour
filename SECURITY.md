# Security Policy

powerhour is a self-hosted personal finance app, so security reports are especially welcome.

## Supported Versions

The `main` branch is the only supported development line.

## Reporting a Vulnerability

Please do not open public issues for vulnerabilities.

Report security issues by emailing the maintainer listed in the repository profile, or by opening a private vulnerability report on GitHub if available. Include:

- A short description of the issue
- Steps to reproduce or a proof of concept
- The affected commit, version, or deployment configuration
- Any known impact or mitigation

I will acknowledge valid reports as soon as possible and coordinate a fix before public disclosure.

## Sensitive Data

Never include real Plaid tokens, bank data, `.env` values, API keys, or passwords in bug reports, screenshots, fixtures, or pull requests. Use demo mode or synthetic data instead.
